1. ^ vs ~ (Very Short – Interview Ready)

^ (caret) → allows minor + patch updates
Example: ^1.2.3 → 1.x.x (but not 2.0.0)

~ (tilde) → allows only patch updates
Example: ~1.2.3 → 1.2.x

One-line answer (perfect for interview):
^ is flexible (minor + patch updates), ~ is strict (patch updates only).

2. What is npm?
npm stands for Node Package Manager
It is the default package manager for Node.js
Used to install, manage, and share JavaScript libraries

What problem does npm solve?
Before npm:
Manually download JS files
Manually manage versions
Difficult dependency handling

With npm:
Automatic installation
Version control
Dependency management

What can you do with npm?
Install libraries (React, Angular, Axios, etc.)
Manage project dependencies
Run scripts (build, test, start)
Share your own packages

Key npm terms (Very Important)
1️⃣ Package
A reusable piece of code
Example: react, lodash

2️⃣ Dependency
A package your project needs to work

3️⃣ node_modules
Folder where installed packages are stored
Auto-generated (not committed to Git)

4️⃣ package.json
Configuration file for a project

Contains:
Project info
Dependencies
Scripts

Common npm commands (Must remember)
npm init          # create package.json
npm install       # install all dependencies
npm install react # install a package
npm uninstall pkg # remove a package
npm start         # run app
npm run build     # build app

Local vs Global installation
Type	Use case
Local	Project-specific libraries
Global	CLI tools (npm, nodemon, etc.)

Example:

npm install -g nodemon

npm vs CDN (Interview Favorite)
npm	CDN
Used in real projects	Used for learning/demo
Bundled with tools	Loaded via script tag
Version controlled	Less control
Production-ready	Not scalable
npm in React projects

React apps use npm to:
Install React
Manage dependencies
Build production bundles

Example:
npx create-react-app myApp
npm vs npx (Short)
npm → installs packages
npx → runs packages without installing globally
Interview One-Liners

package.json defines project dependencies
node_modules contains installed packages
